# TVASRs (A Time Viking and Space Viking Port with 4 Player Co-op)
A port of Time Viking and Space Raptor by Ska Studios with added 4 player co-op based on the code from I Made A Game With Zombies In It.
No keyboard support was added so you need 1-4 controllers.
No online multiplayer was added so you need to use [Parsec](https://parsec.app/)

## Who Made This

Time Viking and Space Raptor was made entirely by Ska Studios, this is a port I made with AI assistance from Claude. I put up this recompilation due to the end of Xbox Live Indie Games thusly not having a reliable way to play this game and wanting to play with more than 2 players. This port will be taken down upon request from Ska Studios, or whenever an official PC port comes around (although I hope they consider making it 4 player instead of 2 player like this).

## Downloading and Running

1. Get the latest build from the [Releases page](../../releases) (newest version on top).
2. Unzip it anywhere on your PC.
3. Run `TVASR(S).exe`.

No installer or admin rights are needed as it's a portable folder. To update, download the new release and unzip over (or replace) the old folder.
